NETFLIX USER BEHAVIOR ANALYTICS DASHBOARD

1. Project Title / Headline

Netflix User Behavior Analytics Dashboard: Viewer Engagement & Streaming Insights

An interactive Power BI dashboard designed to analyze Netflix user behavior across countries, subscription plans, demographics, viewing patterns, devices, and content preferences. The dashboard helps stakeholders understand user engagement, content consumption trends, and platform performance through data-driven insights.

2. Short Description / Purpose

The Netflix User Behavior Analytics Dashboard provides a comprehensive view of user activity, watch time, ratings, subscription distribution, and content preferences across multiple dimensions. It enables business analysts, content strategists, and platform managers to monitor user engagement, identify viewing trends, evaluate subscriber behavior, and support strategic decision-making.

3. Tech Stack

The dashboard was built using the following tools and technologies:

- Power BI Desktop – Primary platform for dashboard creation and data visualization.
- Power Query – Used for data cleaning, transformation, and preparation.
- DAX (Data Analysis Expressions) – Developed calculated measures, KPIs, and analytical metrics.
- Data Modeling – Created relationships between user, subscription, content, and demographic datasets.
- Interactive Visualizations – KPI cards, maps, donut charts, bar charts, slicers, and trend analysis visuals.
- File Format – .pbix for development and .png for dashboard presentation.

4. Data Source

Source: Netflix User Behavior Dataset (Kaggle)

The dataset contains Netflix user activity and engagement information, including:

- User demographics
- Subscription plans
- Content interactions
- Watch time statistics
- Ratings provided by users
- Preferred genres
- Device usage information
- Country-wise user distribution
- Content engagement metrics

The dataset enables comprehensive analysis of streaming behavior and audience preferences across multiple segments.

5. Features / Highlights

Business Problem

Streaming platforms generate massive volumes of user interaction data every day. Without a centralized analytics solution, it becomes difficult to answer critical business questions such as:

- Which countries contribute the most active users?
- Which subscription plans are most popular?
- What genres attract the highest audience engagement?
- How does watch time vary across different age groups?
- Which devices are most frequently used for streaming?
- How satisfied are users based on ratings provided?

Manual analysis of these datasets can be time-consuming and may lead to missed opportunities for content optimization and customer retention.

Goal of the Dashboard

The dashboard aims to:

- Monitor overall user engagement.
- Analyze subscription plan distribution.
- Understand demographic viewing patterns.
- Evaluate content preferences across genres.
- Track user ratings and satisfaction levels.
- Identify device usage trends.
- Compare country-wise user activity.
- Support content and business strategy decisions through interactive visualizations.

Business Impact & Insights

User Engagement Optimization

The dashboard helps stakeholders identify viewing patterns, user preferences, and engagement trends to improve content recommendations and customer retention.
